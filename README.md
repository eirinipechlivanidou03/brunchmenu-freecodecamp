
# Brunch Menu 🥑☕ - Fili

A clean, responsive brunch menu built with semantic HTML5 and CSS.

### About This Project
This project was originally inspired by the **Cafe Menu** practice project on freeCodeCamp. After completing the curriculum exercise, I redesigned and customized it into a full brunch menu to experiment with new content, layout adjustments, and make it my own.

### What I Practiced:
- **Semantic HTML5:** Using clean landmark and structural tags (`main`, `section`, `article`, `footer`).
- **CSS Box Model:** Applying `margin` and `padding` for balanced spacing and visual breathing room.
- **Layout & Alignment:** Aligning menu items and prices side-by-side using `display: inline-block` and percentage widths.
- **Centering & Flow:** Clean element centering using `margin: auto` with max-width boundaries.
