# coffeemenu-freecodecamp

Coffee Menu ☕🍰  
A responsive coffee shop menu built with HTML5 and CSS.   
This project was built to practice CSS fundamentals: the box model, margins &amp; padding, centering elements, and structuring content with clean, semantic HTML.
